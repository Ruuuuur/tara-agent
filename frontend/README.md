# Tara Agent 前端

前端使用 Next.js、React 和 TypeScript，负责用户操作和结果展示。科学计算由后端完成。

## 首页导览

登录页和新对话空白页介绍 Tara Oceans 数据背景、当前可用的分析类型和三步入门方法。新用户可以登录或以游客身份进入，选择示例问题，也可以直接输入研究问题；查看结果时应阅读数据说明，并可打开分析链路核对来源与执行步骤。

首页提供 Tara Oceans 航次介绍与 Ocean Gene Atlas 的外部链接。Ocean Gene Atlas 是独立网站，不是 Tara Agent 的内置工具或本次分析的数据来源。介绍内容位于 `src/components/project-intro.tsx`，中英文文案位于 `src/lib/ui-translations.ts`，页面布局位于 `src/app/globals.css`。

工具明确标记的最终表图优先于外层步骤角色，部分完成时仍展示已生成的核心结果。图表使用 `artifact_key` 匹配产物，旧会话兼容原有标题；受阻项目不补造图表。处理过程使用用户能理解的说明，原始规划和图号仍保留在执行记录与响应中。

## 界面语言

登录页、聊天页顶部和分析记录页提供 `English / 中文` 切换按钮。默认中文，选择保存在当前浏览器的本地存储中，刷新后恢复；禁用本地存储时仍可在当前页面切换。切换不会清空输入、会话或进行中的分析。

中英文切换只控制按钮、栏目标题（如“分析过程”“数据说明”）、状态（如“部分完成”）和受控示例问题。回答、澄清和规划语言由后端按本轮提问判断：明确指定中英文时优先遵循；否则跟随提问正文，“继续”等简短追问沿用上一轮回答。回答区域内的正文、过程说明、数据说明、图表标题/坐标轴/悬停、表头和结果值按该轮回答语言展示，不随 UI 开关重新翻译；旧会话以保存的回答正文识别语言，刷新恢复一致。固定科学模板可按该轮语言显示，未知诊断、原始数据和标识保留原文；不触发模型翻译或双语生成。下载按钮和分页等控件随 UI 切换，导出文件名跟随该轮内容语言，CSV/FASTA 内容保留原值。

翻译词典位于 `src/lib/ui-translations.ts`，示例问题模板翻译位于 `src/lib/suggestion-question.ts`，语言上下文与按钮位于 `src/components/language-provider.tsx`。新增界面文案应同步补充中文和英文，不在翻译过程中修改工具参数或科学结果。无需新增依赖、数据库字段或迁移。

## 首次运行与日常开发

首次运行按[根目录 README](../README.md)准备工具、本机数据库和模型配置、校内数据服务连接，并安装前后端依赖；本机不放置科学数据集。数据库和后端启动后，在 `frontend/` 执行：

```powershell
# 启动前端开发服务；修改代码后自动更新页面。
pnpm dev
```

访问 `http://localhost:3000`。日常开发直接运行上述命令；只有前端依赖或锁文件变化时，才需要在本目录执行 `pnpm install --frozen-lockfile`，按锁定版本重新安装依赖。

本地开发无需创建 `.env.local`。前端默认通过同源 `/api` 路径转发到 `http://127.0.0.1:8000/api`。

若后端使用 8001，在 `frontend/.env.local` 设置 `TARA_API_PROXY_TARGET=http://127.0.0.1:8001`，重启前端即可。本地默认接受 `http://localhost:3000` 和 `http://127.0.0.1:3000`，认证请求走同源代理。同一登录会话应保持使用同一个主机名，两个地址的浏览器 Cookie 不共享。若改用其他端口、域名或局域网 IP，还需同步后端 `TARA_CORS_ORIGINS` 并重启，不能仅修改前端代理。显式配置的来源列表会覆盖默认值。

Docker 部署使用 `standalone` 正式构建，页面、静态文件和地图资源由前端容器提供，`/api` 由 Caddy 转发。镜像构建时关闭本机 API 代理。整套应用的启动命令见 [Docker 部署指南](../deploy/README.md)。

## 修改后检查

以下命令在 `frontend/` 执行，用于检查改动，不是启动步骤：

```powershell
# 验证错误提示、字段校验和语言切换回归。
pnpm test

# 检查代码规范和常见错误。
pnpm lint

# 检查 TypeScript 类型。
pnpm typecheck

# 检查能否完成生产构建。
pnpm build
```

修改交互后，还应在页面验证对应操作，包括加载失败、登录失效和刷新后的显示。修改聊天流时，检查成功、失败和中断时的提示；修改分析展示时，检查表格、图表和来源信息。

回复卡片使用一个批量切换按钮，在“全部折叠”和“全部展开”之间切换，只影响当前轮；单卡片仍可独立展开，实时生成的新卡片沿用该轮最近一次批量选择。提问索引只列当前对话的用户指令，按原顺序跳转到对应轮。浏览历史或回到顶部时暂停自动跟随，点击底部或发送新问题后恢复。折叠和索引打开状态只保存在当前页面，不写入数据库；刷新或重新打开会话时恢复默认显示。

链路追溯的“数据与筛选”保留紧凑标签，用简短文字连接数据集和各轮条件。共同的数据版本、类群和标记只显示一次；实验层、排名与目标功能按实际调用分别展示。长名单显示总数，完整名单可通过标签提示及节点详情查看；原始参数和来源记录保留在详情中，未记录的范围不推断为全量分析。

首页问题按任务类型和科研主题轮换，包括基础查询、丰度、多样性、环境关联与有工具支持的多步骤分析。卡片直接显示涉及的数据集原始文件名，不设折叠。空首页的输入区参与正常布局；小屏或信息较多时允许正常滚动。属/种组成表显示完整样本占比、所选类群内占比及累计占比，保留未鉴定分类，并支持导出完整返回集 CSV。

分析方法按实际工具 Span 的执行顺序列出每次调用，显示调用轮次、MCP 工具本名和对应的中文说明。

回复、图表标题和链路详情共享来源展示：已知数据集标识转换为原始文件名后去重，分别列出本次实际涉及的原始数据、论文参考资料及其他来源。九份已接入原始数据不包含论文辅助资料；未知来源原样保留。长文件名完整换行，历史消息与实时回复一致；原始来源记录不修改。

## 配置与开发约定

会话默认只挂载核心最终产物，前置检索、计算输入、坐标、覆盖与排除记录保留在回复末尾的按需选择器中；勾选后才显示对应表图，取消勾选可收起。功能研究按排名贡献、粒径分布、海区分布和DUF285/LHC信号及环境PLS四组展示，额外比较产物按需查看。科学警告与部分完成提示保持可见；完整结果、下载和链路不裁剪。历史消息沿用同一选择逻辑，刷新后恢复仅展示核心结果。

- 只有需要更改 API 地址或通过外部域名访问开发服务器时，才在本目录创建 `.env.local`；可配置项见 [`.env.example`](.env.example)。`TARA_ALLOWED_DEV_ORIGIN` 填域名，不含协议。修改配置后重启前端。
- `NEXT_PUBLIC_` 开头的配置会公开给浏览器，不放模型密钥或数据库密码。
- API 调用集中在 `src/lib/api.ts`；修改接口数据结构时，同步更新后端定义与 `src/lib/types.ts`。
- 前端展示后端返回的统计结果、来源、警告和图表数据，不自行重算科学结果。
- 聊天逐步接收后端事件；连接结束但未收到完成或错误事件时，应显示异常，不能当作成功。
- 分析过程页面按真实父子关系展示同一棵执行树，不另建一套科学步骤记录。

团队规范与后续方向见 [AGENTS.md](../AGENTS.md) 和[项目方案](../tara-agent方案文档.md)。


PLS 相关圆直接显示全部环境变量和响应指标名称。拥挤标签按原纵坐标在圆左右两侧排开，细线连接原始点；文字位置不是新的变量坐标。圆内向量从原点指向变量坐标。MetaG 与 MetaT 分别用橙色与红色，环境变量为蓝色；非功能群落响应继续使用独立响应颜色。网页和PNG导出共用同一图层，不改变科学坐标或输入数据。


### 界面语言浏览器回归

`scripts/test-ui-i18n.cjs` 使用独立 Playwright 浏览器和合成 API 数据，默认连续运行三轮，覆盖桌面/手机、八种图表、过程与数据说明、补充结果、CSV 与分页、中英文往返切换和桌面历史刷新。逐字断言已生成的英文回答在切换为中文界面、切回英文界面及历史恢复后保持一致，同时比较过程说明、数据说明、表格内容及 Plotly 数据/标题/坐标轴在切换前后完全一致，栏目标题仍随界面切换。检查可见文字、辅助标签及 Plotly 的实际标题、轴、图例和悬停文字；仅排除语言切换按钮的目标语言名称及原始参数区。不会登录真实账户、调用模型或写入服务器数据，不能替代科学计算验收。

在已安装 Playwright 的环境执行：

```bash
TARA_AUDIT_URL=http://localhost:3000 node scripts/test-ui-i18n.cjs
```

可设置 `TARA_AUDIT_CONTENT_LANGUAGE=zh` 专测中文回答内容在切换及历史恢复后不变；该模式不运行英文残留扫描，因为中文生成内容应当保留。默认 `en` 同时进行英文残留检查和内容不变检查。

可通过 `TARA_PLAYWRIGHT_MODULE` 指定已有模块路径、`TARA_CHROME_PATH` 指定浏览器、`TARA_AUDIT_ROUNDS` 指定正整数轮数、`TARA_AUDIT_OUTPUT` 指定报告路径。默认报告 `/tmp/tara-i18n-audit/report.json`；任何遗漏或未完成场景均返回非零退出码。
